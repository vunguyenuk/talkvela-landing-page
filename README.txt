TalkVela landing page (prototype)

Open index.html directly, or run  python3 -m http.server 8080  and visit http://localhost:8080

Sections
 1. Header + hero "English you can actually speak" (scroll-driven practice film)
 2. Tap to speak vs. speak continuously (2 demo cards)
 3. Statement + how a session works (4 steps)
 4. Every skill, one conversation (4 rows + 2x2 grid, live chat UI)
 5. Principles: Trust / Challenge / Teach
 6. Who it's for (working professionals / newcomers abroad)
 7. Call to action + footer
